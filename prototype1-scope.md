This prototype should focus on a small gameplay loop of the actual scanning and checking of ships.
The goal being to see if it's fun and to tease out potential future issues and improvements.

Let's start with 1 ship that the player is in command of.
It is equipped with the modules needed to perform their initial duties.
- Scanner(s?)
- Main gun/missile for defence or enforcement
- point defence, defensive missiles for defence.


Ships enter the playspace for an amount of time, for the player to discover and action any issues with them.
Failure to detect an issue before the ship leaves results in a penalty.

## Interface

For this prototype I think a point-and-click, buttons interface rather than a terminal.

Let's see if we can get away with text-only and minimal-no images, just interface.

Let's build it with web-technology, so it's deployable and testable within a browser.
